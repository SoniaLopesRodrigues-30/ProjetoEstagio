# 📊 Sistema de Controle de Dados

Este é um sistema web desenvolvido para centralizar, gerenciar e monitorar o fluxo de informações de forma simples e eficiente. 
O projeto resolve o problema de descentralização de dados, permitindo a organização e visualização rápida das informações direto no navegador.

## 📷 Demonstração
# 📊 Sistema de Controle de Dados

Este é um sistema web desenvolvido para centralizar, gerenciar e monitorar o fluxo de informações de forma simples e eficiente. 
O projeto resolve o problema de descentralização de dados, permitindo a organização e visualização rápida das informações direto no navegador.

## ⚙️ Funcionalidades Principais
- **Gerenciamento de Dados:** Criação, leitura, atualização e exclusão de registros (CRUD).
- **Interface Responsiva:** Adaptada para telas de computadores, tablets e celulares.
- **Armazenamento Local:** Uso de recursos do navegador para persistência de dados.
- **Filtros de Busca:** Localização rápida de informações cadastradas.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização, layout e responsividade do sistema.
* **JavaScript (ES6+):** Lógica do sistema, manipulação de dados e interatividade.

## 🚀 Como Executar o Projeto

Como o sistema é feito com tecnologias web nativas, você não precisa instalar nenhuma dependência. Siga os passos:


### Abrir o Sistema
Basta abrir o arquivo **`index.html`** em qualquer navegador web (Chrome, Edge, Firefox) dando um duplo clique sobre ele.
